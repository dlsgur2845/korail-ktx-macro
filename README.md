# KTX 잔여석 매크로

코레일 일반 예매 웹에서 원하는 KTX 좌석을 감시하고, 좌석 선택과 예매 요청을 보조하는 Chrome 확장 프로그램입니다. **결제는 직접 진행합니다.** 명절 전용 예매 사이트는 지원하지 않습니다.

현재 버전 **1.5.3** · [릴리스 노트](RELEASE_NOTES.md)

## 설치·업데이트

1. 저장소 또는 배포 ZIP을 내려받아 압축을 풉니다.
2. Chrome의 `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**로 `manifest.json`이 있는 폴더를 선택합니다.
4. 코레일 탭을 새로고침합니다.

업데이트: **감시 중지 → 기존 폴더 파일 교체 → 확장 프로그램 새로고침 → 코레일 탭 새로고침**.

사용에는 Node.js·Python 등 별도 프로그램이 필요하지 않습니다. 자동 클릭에 `debugger`, PC 알림에 `notifications`, 휴대폰 알림 설정 저장에 `storage` 권한을 사용합니다. 자동 실행 중에는 Chrome 개발자 도구를 닫아주세요.

## 사용 방법

1. 코레일에 로그인하고 편도 날짜·구간·인원을 지정해 열차를 조회합니다.
2. **특정 열차** 또는 **시간대** 중 하나를 감시 기준으로 선택합니다. 열차 번호는 여러 개 입력하거나 목록에서 선택할 수 있습니다.
3. 좌석 등급·예약 목표(1~6장)·발견 시 동작을 고르고 **감시 시작**을 누릅니다.
4. 알림이 오면 예약 내역과 결제 기한을 확인하고 직접 결제합니다.

상단 카드에서 대상 열차·출발 시각·구간을 확인할 수 있습니다. `−` 버튼으로 최소화해도 감시는 계속됩니다.

## 여러 장 예약

웹 조회 인원은 **1명**, 확장 프로그램의 예약 목표는 **2장 이상**, 발견 시 동작은 **예매 요청**으로 설정하세요. 첫 예약이 확인되면 해당 열차로 고정하고 한 장씩 추가 예약합니다. 떨어진 좌석도 허용하며 상단과 최소화 화면에 `1/2장`처럼 표시합니다.

예약번호·날짜·열차·인원·좌석을 확인해 집계하며 목표 수량에 도달하면 정지합니다. 상세 화면 형식을 읽지 못하면 추가 예매 없이 멈춥니다. 여러 장 모드는 모의 화면으로 검증했으며 **로그인 후 실제 연속 예약은 아직 미검증**입니다.

먼저 확보한 표의 결제 기한이 2분 이내이거나 기한을 읽지 못하면 정지하고 알립니다. 각 예약은 직접 결제해야 하며, 일부만 확보한 채 종료될 수 있습니다. 집계는 이 실행에서 확인한 예약 건수로, 다른 탭에서 결제·취소한 결과는 자동 반영하지 않습니다. 중지 후 같은 설정으로 재개하면 집계를 유지합니다. 새 목표는 예약 내역 확인 후 **예약 집계 초기화**를 누르세요. 이 버튼은 실제 예약을 취소하지 않습니다.

## 동작 기준

선택한 열차의 지연(지연배상 없음)·우회·단체 위약금 안내·좌석 자동배정은 자동으로 동의·확인합니다. 조회는 브라우저 일반 새로고침(F5에 해당)을 사용하며 별도 설정이 필요하지 않습니다.

- 특정 열차는 최초 목록과 더보기 최대 2회까지 찾습니다. 시간대는 종료 시각을 포함하는 범위까지 더보기를 진행합니다. 웹 조회 시작 시각보다 앞선 열차는 검사할 수 없습니다.
- 특정 열차 모드는 선택한 번호를 기준으로 하며 인접역 열차도 포함할 수 있습니다. 시간대 모드는 조회 구간과 출발 시간대를 함께 확인합니다.
- 좌석을 발견하면 해당 열차에 집중합니다. 명확한 **잔여석 없음** 안내는 닫고 같은 선택을 유지해 예매만 재시도합니다.
- 예매 결과가 불명확하거나 서버 오류·로그인·접근 제한 안내가 있으면 정지합니다. 결제나 알 수 없는 안내창은 자동 처리하지 않습니다.
- 조회 오류 시 대기 시간을 늘려 복구를 시도합니다. 조회 후 대기와 쉬어가기는 추가 설정에서 변경할 수 있습니다.

## 알림

**PC:** 알림 설정에서 테스트할 수 있습니다. Chrome 알림 허용 및 운영체제의 집중 모드 설정을 확인해주세요.

**휴대폰:** **알림 설정 → 휴대폰 알림 연결 · ntfy**를 엽니다.

1. 휴대폰에 [ntfy 앱](https://docs.ntfy.sh/subscribe/phone/)을 설치하고 알림을 허용합니다.
2. 서버 `https://ntfy.sh`와 연결 화면의 주제 이름으로 구독합니다.
3. PC에서 휴대폰 알림 사용을 켜고 저장한 뒤 테스트 알림을 보냅니다.

ntfy 연결 권한은 켤 때만 요청합니다. 주제 이름을 아는 사람은 알림을 읽거나 보낼 수 있으므로 공유하지 마세요. 상태 문구만 전송하며 날짜·구간·예약번호·쿠키는 보내지 않습니다. 서버 전송 성공과 휴대폰 수신은 별도로 확인해야 합니다.

## 참고

- 실행 중에는 PC와 Chrome을 켜두세요. 절전·탭 종료·로그인 만료에 영향을 받습니다.
- 감시 조건·실행 상태·여러 장 집계(예약번호·좌석·결제 기한)는 탭의 세션 저장소에, ntfy 설정은 확장 프로그램의 로컬 저장소에 저장됩니다. 다른 PC에는 자동 동기화되지 않습니다.
- Chrome에서 화면과 일부 동작을 검증했습니다. 실제 매진 경쟁 상황의 좌석 확보를 보장하지 않습니다.
- 개발용 테스트: Node.js 환경에서 `npm test`.
