# KTX 잔여석 매크로

2026-09-16 코레일 일반 예매 웹 `https://www.korail.com/ticket/search/list`에서 확인한 열차 카드 구조로 만든 크롬·엣지 확장 프로그램입니다. 현재 버전은 **반복 조회 → 잔여석 알림 → 선택적으로 좌석 클릭**까지 지원합니다. **예매 완료/표 확보와 결제는 자동으로 하지 않습니다.** 명절 전용 사이트는 지원하지 않습니다.

## 설치

1. ZIP 파일을 압축 해제합니다.
2. 크롬 주소창에 `chrome://extensions`를 입력합니다. 엣지는 `edge://extensions`입니다.
3. ‘개발자 모드’를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 누릅니다.
4. `manifest.json`이 들어 있는 `korail-ktx-macro` 폴더를 선택합니다.
5. 코레일 웹페이지를 새로고침합니다. 오른쪽에 매크로 패널이 나타납니다.

별도의 Python·Node 설치는 필요 없습니다. 확장 프로그램은 코레일 일반 예매 페이지에만 적용되며 알림 권한을 사용합니다.

## 사용

1. 코레일에서 로그인하고 **편도**의 출발역·도착역·날짜·인원·조회 시작 시각을 직접 지정한 뒤 열차를 조회합니다.
2. 매크로 패널에서 출발 시간 범위, 감시할 열차(필수, 한 개 이상), 일반실/특실을 설정합니다.
3. **현재 조회 열차에서 선택**을 누르고 체크박스로 한 개 또는 여러 개를 선택합니다. 번호를 `031, 033`처럼 직접 입력해도 됩니다. 선택한 번호 중 어느 하나에서 조건에 맞는 좌석이 나오면 알립니다. 목록에 안 보이는 열차는 웹의 더보기를 누른 뒤 선택 목록을 다시 불러오세요. 이미 선택한 다른 번호는 유지됩니다.
4. 고정 간격 대신 **화면 응답 완료 후 재조회**합니다. 최소 대기는 기본 3초(설정 2~60초), 실행 시간은 기본 12시간(1~24시간)입니다. 실제 대기는 최소 대기와 화면 응답 시간의 2배 중 긴 쪽이며, 응답에 따른 추가 대기는 최대 30초입니다.
5. ‘조회 범위’는 최초 목록과 ‘더보기’를 합친 묶음 수입니다. 기본 3묶음, 최대 10묶음까지만 검사합니다. **원하는 시간대가 조회 범위 안에 들어오도록 웹의 조회 시작 시각도 설정하세요.** 매크로 시간대 설정은 결과를 거르는 조건이며 웹 검색 시각을 바꾸지 않습니다.
6. ‘알림 후 정지’ 또는 ‘좌석 선택 후 정지’를 선택하고 시작합니다.
7. 알림을 받으면 코레일에서 안내창을 확인하고 하단 **예매**를 직접 눌러 완료합니다. 알림을 받았더라도 먼저 예약한 사람이 있으면 좌석이 소진될 수 있습니다.

매크로 패널의 ‘중지’로 종료할 수 있습니다. 탭을 닫으면 종료됩니다. 시스템 알림을 받으려면 운영체제에서 브라우저 알림이 허용되어 있어야 합니다. 절전, 브라우저 종료, 탭 절약 모드에서는 실행이 지연되거나 중단될 수 있습니다. 브라우저가 타이머를 늦출 수 있어 즉각적인 반응을 보장하지 않습니다. 이 버전은 조회 응답을 기준으로 동작하며 예약 실패 버튼을 반복 클릭하지 않습니다.

## 동작

- 현재 화면의 `li.tckList`, 열차 번호, 구간, 출발 시간, 일반실·특실 가격을 읽습니다.
- ‘매진임박’과 가격이 함께 표시된 일반실·특실을 인식합니다. 매진과 예약대기는 제외합니다. 입석+좌석은 기본 제외하며, ‘입석+좌석도 포함’을 켜면 일반실 감시에서 함께 감지합니다. 특실만 선택한 경우 적용하지 않습니다. 순수 입석은 감지하지 않습니다.
- 화면을 0.5초마다 읽습니다(서버 요청이 아닌 로컬 검사). 로딩 표시가 없고 목록이 0.75초 이상 안정되어야 조회 완료로 간주합니다. 실제 네트워크 요청 완료를 직접 관측하는 방식은 아니므로 사이트가 표시하지 않는 로딩은 판별하지 못할 수 있습니다.
- 완료 후 응답 속도에 따른 대기를 거쳐 새로고침합니다. 대기 중 목록이 변경되면 먼저 새 목록을 검사합니다. 로딩 또는 대기열이 있으면 추가 요청을 보내지 않습니다. 불규칙한 난수를 넣거나 사람처럼 위장하는 방식은 아닙니다.
- 출발역·도착역·날짜·인원이 바뀌면 정지합니다.
- 접속 대기열에서는 재조회하지 않고 기다립니다. 인증·접근 제한 안내를 감지하면 정지합니다.
- 열차 목록이 60초 동안 비어 있으면 30초 이상, 60초 이상으로 대기를 늘려 재시도하고 세 번째 실패 시 정지합니다. 표시된 로딩 또는 더보기가 60초 이상 끝나지 않으면 정지합니다.
- 같은 사이트 주소에서 여러 탭이 실행되는 것을 잠금과 만료 시간으로 방지합니다. `www.korail.com`과 `korail.com`은 브라우저에서 별도 사이트 저장소이므로 둘을 동시에 실행하지 마세요.
- 발견하면 **먼저 반복 실행을 중지한 뒤** 알림과 선택 동작을 수행합니다. ‘잔여석 없음’ 안내를 자동으로 닫고 예약 버튼을 반복 클릭하는 기능은 없습니다.
- 로그인 정보는 읽거나 저장하지 않습니다. 검색 조건·실행 상태만 해당 탭의 세션 저장소에 저장합니다. 서버 API 직접 호출, 탐지 회피, 대기열 우회 기능은 없습니다.

## 확인한 범위와 한계

- 실제 개편 웹에서 열차 목록, 매진/가격/매진임박 표시, 가격 선택 후 하단 예매 버튼, 새로고침 후 조회 조건 유지까지 확인했습니다.
- 구간·번호·시간 필터와 좌석 상태 판별 테스트 20개(필터·대기 정책·모의 화면 실행 흐름)를 통과했습니다. JavaScript 구문 검사를 통과했습니다.
- 확장 프로그램을 브라우저에 설치한 통합 시험, 장시간 연속 실행, 로그인 후 예약 성공·실패 흐름은 아직 검증하지 않았습니다.
- 예전 웹의 ‘잔여석 없음 이후 같은 예약 버튼 재시도’ 방식이 새 웹에서도 가능한지는 미확인입니다. 따라서 본 버전은 자동 예약 매크로의 완성본이 아니라 잔여석 조회·선택 버전입니다.
- 향후 사이트 구조가 바뀌면 선택자 수정이 필요합니다. 낮은 조회 빈도도 사이트에서 허용되거나 탐지되지 않는다는 보장은 없습니다.

## 기존 버전 업데이트

새 ZIP을 풀어 기존 확장 프로그램 폴더의 파일을 교체한 뒤, 확장 프로그램 관리 화면에서 해당 확장의 새로고침을 누르고 코레일 탭도 새로고침하세요. 1.0 설정의 실행 상태는 중지되며 최소 대기 3초로 전환됩니다. 열차를 선택하고 다시 시작해주세요.

## 1.1.2 수정

- ‘해당 스케줄에 운행하는 열차가 없습니다’ 안내를 로딩 대기와 구분하여 정지합니다. 이는 매진 판정이 아닙니다. 직전 동작(더보기/새로고침)을 함께 표시합니다.
- 선택한 열차를 모두 확인한 경우 불필요한 더보기 요청을 하지 않습니다.
- 빈 결과의 서버 측 원인은 아직 확인되지 않았습니다. 이 상태에서는 매크로를 중지하고 웹에서 원래 조건으로 다시 조회한 뒤 실행하세요.

## 1.1.3 수정

조회 설정의 펼침·접힘 상태를 탭의 세션 저장소에 별도로 저장합니다. 같은 탭에서 자동·수동 새로고침을 해도 유지되며, 실행을 다시 시작해도 초기화되지 않습니다.

## 1.1.4 수정

입석+좌석 포함 옵션을 추가했습니다. 기본은 꺼짐이며 일반실 또는 일반실 우선 설정에서 적용됩니다. ‘좌석 선택 후 정지’ 모드에서는 입석+좌석 링크를 클릭하고 안내창과 예매는 사용자가 진행합니다. 실제 예약 성공 흐름은 미검증입니다.
